# IST256 - Group Project Cafe

## Cozy Corner Cafe Website

The complete MongoDB-integrated Node.js application
is located in the `cafe-mongodb/` folder.

[View the application source](cafe-mongodb/)

[Setup instructions and documentation](cafe-mongodb/README.md)

### Technology Stack

Node.js, Express, MongoDB, Mongoose, HTML, CSS,
Bootstrap, JavaScript, AngularJS, React, and jQuery.

### Running the Project

Open a terminal in `cafe-mongodb/`.

Run:

npm install

Configure the .env file.

npm run seed

npm start

Open http://localhost:3000

See the project README for detailed instructions.
